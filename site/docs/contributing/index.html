Contributing

Contributions preserve both distribution paths.

Pocket Desktop accepts code, documentation and original theme assets under a GPLv3 + Commercial dual-license model.

Workflow

Open an issue before substantial product, protocol or theme work. Pull requests use Conventional Commit titles and must pass the native, Linux distribution and WebAssembly preview checks.

$ bun run setup
$ bun run check
$ bun run build
